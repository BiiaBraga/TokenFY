# TokenFY

TokenFY é um projeto desenvolvido durante o HackMT — Edição Água Boa (MT), realizado em outubro de 2024.
O projeto conquistou o 🥈 segundo lugar da competição e teve como principal objetivo propor uma solução para problemas relacionados ao controle e gerenciamento de almoxarifado na região.
A aplicação foi desenvolvida como uma solução web voltada para organização e gerenciamento de informações de estoque e autenticação de usuários.

---

## 🚀 Funcionalidades

* Cadastro de usuários
* Login e autenticação
* Controle de informações do almoxarifado
* Interface interativa
* Navegação entre páginas
* Sistema integrado de gerenciamento

---

## 🛠 Tecnologias Utilizadas

* Python
* HTML5
* CSS3

---

## ⚙️ Como Executar o Projeto

### Clone o repositório

```bash
git clone https://github.com/BiiaBraga/TokenFY.git
```

---

### Acesse a pasta do projeto

```bash
cd TokenFY
```

---

### Execute a aplicação

```bash
python main.py
```
